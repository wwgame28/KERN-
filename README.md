# Merge Bastion: Evolution

Браузерная игра для **Яндекс Игр**: слияние турелей (merge) + idle tower defense.
Чистый Canvas 2D и Vanilla JS, без фреймворков. Графика и звук взяты из бесплатных паков Kenney (CC0),
шрифт Russo One (OFL). Всего 552 КБ.

**Как играть:** волны треугольников спускаются к стене бастиона. Покупай турели 1 ур., перетаскивай
одинаковые друг на друга (1+1 = 2, 2+2 = 3 … до 12 ур.). Верхний ряд (оборона) стреляет сам, сетка
слияния под ним служит складом. Чтобы продать турель, перетащи её на кнопку «Купить».

## Структура

```
index.html          вся логика игры
assets/atlas.png    атлас спрайтов (81 спрайт)
assets/bundle.js    координаты спрайтов + 19 звуков (MP3) + шрифт, всё в base64
assets/CREDITS.md   источник и лицензия каждого файла
tools/              сборщик ассетов и симулятор баланса
```

Звуки и шрифт лежат внутри `bundle.js`, поэтому игра работает и при открытии файла напрямую
(`file://`), где браузер блокирует загрузку аудио и шрифтов. Если `assets/` нет, игра переходит
на процедурную графику и синтезированный звук.

## Запуск

Открой `index.html` в браузере, сервер не нужен.
Параметры: `?lang=ru` / `?lang=en` (язык), `?ysdk` (подгрузить настоящий SDK не на хостинге Яндекса).
Клавиши: `B` купить, `Space`/`P` пауза, `M` звук, `` ` `` отладка (FPS, число сущностей).

## Публикация в Яндекс Игры

```bash
zip -r merge-bastion.zip index.html assets
```
Архив загружается в консоли разработчика Яндекс Игр. На их хостинге игра сама подключает `/sdk.js`,
вне его вызовы рекламы заменяются экранными заглушками.

Что уже сделано под требования площадки:

| Требование | Где в коде |
|---|---|
| `LoadingAPI.ready()` после загрузки | `boot()` |
| `GameplayAPI.start/stop` при игре, паузе, рекламе, меню | `States.play.enter/exit` |
| Rewarded: `showRewardedVideo(cb)` (награда только после `onRewarded`) | `showRewardedVideo` |
| Interstitial: `showInterstitialAd()` не чаще раза в 90 с | `maybeInterstitial` |
| Пауза и отключение звука во время рекламы и при сворачивании вкладки | `openAd`, `visibilitychange` |
| RU/EN по языку SDK или браузера | `I18N`, `pickLang` |
| Нет контекстного меню, выделения текста, зума | обработчики ввода |
| Мышь и тач, адаптив, safe-area (вырез iPhone) | `layout()` |
| Сохранение прогресса (работает и без localStorage) | `Store`, `saveGame` |

## Монетизация и удержание

- **«Турель 3 ур. бесплатно (реклама)»**: rewarded, кулдаун 30 с.
- **Поражение → «Реванш с уроном x2» (реклама)**: в симуляции повтор с x2 почти всегда проходит волну,
  то есть реклама реально помогает. Бесплатная альтернатива: отступить на 2 волны и подкопить монет.
  Турели не теряются никогда.
- **Офлайн-доход**: «С возвращением! +N монет», за рекламу x3.
- **Коллекция эволюций**: 12 уровней с именами (Искра → Генезис), карточка «НОВАЯ ТУРЕЛЬ!» при первом открытии.
- **Боссы каждые 10 волн, элита каждые 5**: босс, коснувшийся стены, сразу роняет бастион.
- Interstitial после каждого 10-го босса и при отступлении (с лимитом частоты).

## Баланс

Все числа лежат в `CONFIG` в начале скрипта. Кривая подобрана бот-симуляцией на реальном коде игры:

```bash
node tools/balance-sim.js 45 3   # «казуальный» игрок: 1 действие в 3 с
node tools/balance-sim.js 45 1   # активный: 1 действие в секунду
node tools/balance-sim.js 45 0   # идеальный бот
```

Текущая кривая (казуальный бот): волны 5–9 без урона стене (онбординг), первое поражение
на боссе 10-й волны (~2,5 мин, первый показ «реванша»), волна 20 примерно за 8 мин, 30 за 18 мин, 40 за 32 мин.
Дальше идут стены на боссах и фарм.

## Архитектура

```
CONFIG → PAL/LEVELS → I18N → utils → Save → Yandex SDK & Ads → Audio → Layout
→ Pools → World → Systems → UI → States → Render → Loop → boot()
```

- Фиксированный шаг 60 Гц с аккумулятором, `requestAnimationFrame`, кламп dt 0,25 с, интерполяция при отрисовке.
- Машина состояний: `menu → welcome → play ⇄ paused / ad / defeat`.
- Пулы объектов для пуль, частиц, врагов и всплывающих текстов, поэтому в кадре нет мусора.
- Статичный фон кэшируется в offscreen-canvas, свечение рисуется кэшированными спрайтами вместо `shadowBlur`.
- Логическая ширина 540, высота подстраивается под экран (960–1170). Скорость врагов задаётся
  в «высотах поля в секунду», поэтому сложность одинакова на любом экране.
- Спрайты рисуются из одного атласа; окрашенные текстуры частиц и белые силуэты для вспышки
  попадания кэшируются в offscreen-canvas при первом использовании.
- Звук: сэмплы Kenney через Web Audio (декодируются после первого касания), синтез как запасной вариант.
