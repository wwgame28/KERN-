# Работа с iPhone: Claude + Xogot

## Что видно на скриншоте
На скриншоте установлено приложение **Xogot**. Его предполагаемая роль в процессе — открывать и запускать Godot-проект на iPhone. Само по себе наличие Xogot не означает, что Claude может управлять редактором напрямую.

## Рекомендуемый процесс
1. Claude создаёт или изменяет файлы проекта в доступной ему рабочей среде/репозитории.
2. Проект сохраняется в GitHub или отдаётся готовым ZIP-архивом.
3. Пользователь загружает ZIP/проект на iPhone и импортирует его в Xogot способом, который поддерживает установленная версия приложения.
4. Пользователь запускает проект в Xogot и присылает Claude скриншот/ошибку.
5. Claude исправляет конкретную проблему и отдаёт обновлённые файлы/архив.

## Что Claude должен выяснить до разработки
- Какая версия Xogot установлена.
- Какой диапазон версий Godot она поддерживает.
- Можно ли импортировать ZIP или нужен каталог проекта.
- Какие ограничения есть у редактора на iPhone.
- Можно ли запускать GDScript и 3D-сцены в текущей версии.
- Поддерживается ли экспорт, или пока доступен только запуск внутри приложения.

Не утверждать, что экспорт iOS/Android/Windows возможен прямо с iPhone, пока это не подтверждено.

## Правила выдачи файлов
- Предпочитать один ZIP с полной структурой проекта.
- В каждом архиве сохранять `project.godot` в корне проекта.
- Не вкладывать проект в несколько лишних уровней папок.
- Добавлять `README_RU.md` с короткой инструкцией.
- Не выдавать только фрагменты кода, если можно отдать целые файлы.
- При исправлении перечислять заменённые файлы.

## Что присылать Claude при ошибке
- Скриншот ошибки.
- Точный текст сообщения, если его можно скопировать.
- Название сцены, которую запускали.
- Что нажали перед ошибкой.
Не отправлять пароли, API-ключи и приватные токены.
