# Задача Claude: Этап 1 — первый запускаемый прототип

Прочитай `CLAUDE.md` и документы `docs/`. Затем создай первый минимальный проект COSMIC SANDBOX.

## Сцена
Небольшая stylized 3D тестовая площадка на первой планете. Добавь простые цветные формы и крупный визуальный ориентир. Не трать время на финальные модели.

## Игрок
- CharacterBody3D.
- Движение относительно направления камеры.
- Прыжок.
- Камера от третьего лица с плавным поворотом.
- Поддержка клавиатуры/мыши и touch UI.

## Гравитация
Добавь два режима: обычная и низкая гравитация. Переключение должно быть доступно через экранную кнопку и отдельное Input Action на ПК. Сила гравитации должна быть централизованной настройкой, а не разбросанными числами по скриптам.

## Портал
Добавь заметный портал-заглушку. При входе в зону и нажатии кнопки взаимодействия показывай сообщение: «Портал пока не активирован». Не создавай фиктивный переход на несуществующую планету.

## Интерфейс
Минимальный HUD:
- подсказка управления;
- кнопка смены гравитации;
- кнопка взаимодействия;
- индикатор текущего режима гравитации.

## Структура и качество
Используй отдельные сцены/скрипты для игрока, планеты, портала и HUD. Все файлы должны находиться в корректных папках. Создай `README_RU.md`.

## Приёмка
Этап считается выполненным, если:
1. Проект открывается без отсутствующих ресурсов.
2. Стартовая сцена запускается.
3. Персонаж двигается и прыгает.
4. Камера работает.
5. Кнопка меняет гравитацию.
6. Портал реагирует на взаимодействие.
7. Мобильный интерфейс не перекрывает весь экран.

В конце дай список тестов. Не называй этап завершённым, если хотя бы один пункт не проверен. Если невозможно проверить из-за отсутствия Xogot, укажи это явно.
