# Ручной тест этапа 1 (Xogot на iPhone)

Отмечайте ✅ / ❌. Если ❌ — скриншот + что нажимали.

## Самопроверка (одна кнопка)
- [ ] Откройте `tests/stage1_self_test.tscn` → запустите текущую сцену.
- [ ] Дождитесь строки «ИТОГ: OK … · FAIL … · SKIP …» (около 20 секунд). Скриншот итога: ____
- [ ] FAIL = 0. (На телефоне SKIP должно быть 0; на ПК без сенсорного экрана допустим 1 SKIP.)

## Запуск
- [ ] Проект открывается в Xogot без красных ошибок в выводе (Output).
- [ ] Запуск проекта показывает парящий остров, небо, газовый гигант и портал впереди.
- [ ] Слева впереди виден высокий тёмный шпиль со светящимся кристаллом и вращающимся золотым кольцом.
- [ ] Слева вверху: «Тестовая планета «Эхо-1»» и «Гравитация: Нормальная · 9.8 м/с²».
- [ ] Справа вверху: FPS и надпись «ПРОТОТИП · этап 1». Запишите значение FPS: ____
- [ ] Подсказка управления под индикатором гравитации остаётся на экране (через ~12 с становится бледнее).

## Управление (touch)
- [ ] Палец в левой нижней зоне → появляется стик, персонаж идёт в сторону наклона.
- [ ] Свайп в правой части экрана вращает камеру (влево/вправо и вверх/вниз).
- [ ] Можно одновременно идти стиком и вращать камеру вторым пальцем.
- [ ] Можно одновременно идти стиком и нажать «Прыжок».
- [ ] Кнопки не перекрыты вырезом/скруглёнными углами экрана.
- [ ] Интерфейс занимает только края экрана, центр (персонаж и мир) свободен.

## Гравитация
- [ ] Прыжок при нормальной гравитации — невысокий (~1.4 м).
- [ ] Кнопка «Грав.» → сообщение «Гравитация: Низкая (3.2 м/с²)», надпись слева вверху меняется.
- [ ] При низкой гравитации прыжок заметно выше и дольше.
- [ ] Платформа A (светлая, справа от портала) запрыгивается при нормальной гравитации.
- [ ] Платформы B и C (тёмные, дальше) запрыгиваются только при низкой гравитации.
- [ ] Повторное «Грав.» возвращает нормальную гравитацию.

## Портал
- [ ] При приближении портал ярче светится, появляются подсказка и кнопка «Действие».
- [ ] «Действие» → окно «Портал «Врата Эхо-1»» с крупной строкой **«Портал пока не активирован»**.
- [ ] Пока окно открыто, персонаж не двигается и touch-управление скрыто.
- [ ] Кнопка «Закрыть» закрывает окно, управление возвращается.
- [ ] При отходе от портала подсказка и кнопка «Действие» исчезают.

## Прочее
- [ ] Шаг с края острова → падение → «Возврат на точку высадки».
- [ ] Камера не проходит сквозь скалы (приближается к персонажу).
- [ ] Поворот телефона в другую альбомную ориентацию не ломает интерфейс.

## ПК (если будет возможность)
- [ ] WASD, мышь (клик для захвата, Esc отпускает), Space, E, G работают.
- [ ] Стрелки вращают камеру без мыши.
