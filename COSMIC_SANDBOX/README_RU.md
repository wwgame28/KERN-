# COSMIC SANDBOX — этап 1 (вертикальный срез)

3D sandbox-adventure на Godot 4.x (GDScript). Это проверяемая основа, а не финальная игра.
Вся графика пока сделана из примитивов (**placeholder**).

## Как открыть в Xogot (iPhone)
1. Скачайте `COSMIC_SANDBOX.zip`: из чата с Claude или из GitHub (`dist/COSMIC_SANDBOX.zip`
   в ветке `claude/new-session-hh4v6e` → кнопка **Download raw file**).
2. В приложении «Файлы» нажмите на ZIP: появится папка `COSMIC_SANDBOX` с файлом `project.godot` внутри.
3. В Xogot откройте/импортируйте папку `COSMIC_SANDBOX` (тем способом, который поддерживает ваша версия Xogot).
4. Дождитесь окончания импорта ресурсов, затем запустите проект (главная сцена уже назначена:
   `scenes/main/main.tscn`).
5. Запустите самопроверку: откройте сцену `tests/stage1_self_test.tscn` и запустите **текущую сцену**
   (Run Current Scene). Она сама походит, попрыгает, переключит гравитацию, активирует портал и
   выведет на экран строки `[OK]` / `[FAIL]` / `[SKIP]` и итог. Сделайте скриншот итога.
6. Пройдите ручной чек-лист из `tests/MANUAL_TEST_STAGE1_RU.md` (внешний вид и настоящие касания
   самопроверка оценить не может). Если что-то не так — пришлите скриншот ошибки, название сцены и
   что вы нажимали.

Если Xogot сообщит, что рендерер не поддерживается: Project → Project Settings → Rendering →
Renderer → выберите `mobile` (для обоих полей Rendering Method и Rendering Method Mobile), сохраните
и перезапустите проект.

## Управление
| Действие | iPhone / Android | ПК | Геймпад | Input Action |
|---|---|---|---|---|
| Ходьба | левый виртуальный стик (появляется под пальцем в левой нижней зоне) | WASD | левый стик | `move_forward/back/left/right` |
| Камера | свайп в правой части экрана | мышь (клик — захват, Esc — отпустить) или стрелки | правый стик | `camera_left/right/up/down` |
| Прыжок | кнопка «Прыжок» | Space | A | `jump` |
| Взаимодействие | кнопка «Действие» (видна только рядом с объектом) | E | X | `interact` |
| Режим гравитации | кнопка «Грав.» | G | Y | `toggle_gravity` |

Все действия заданы в Project Settings → Input Map и переназначаются там.
WASD привязаны к физическим клавишам, поэтому работают и при русской раскладке.

## Технические решения
- **Рендерер:** `GL Compatibility` — самый совместимый вариант (так требует технический план).
  Если на устройстве он не работает или выглядит плохо, переключите на `mobile`.
- **Версия Godot:** проект размечен как 4.3 и не использует возможностей новее 4.3.
  Точная версия Godot в Xogot пока не подтверждена.
- **Настройка гравитации:** сила обоих режимов, направление и подписи хранятся в одном ресурсе
  `resources/planets/test_planet_gravity.tres` (класс `GravitySettings`). Чтобы поменять значения,
  откройте этот файл в инспекторе. В скриптах чисел гравитации нет.
- **Гравитация:** на этом этапе направление гравитации одно (вниз), меняется только сила.
  Сферическая гравитация «маленькой планеты» — это произвольное поле гравитации, а технический план
  просит не делать его до проверки базового движения. Поэтому тестовая планета — плоский участок
  поверхности (парящий остров).
- **GravityController** также задаёт гравитацию физическому пространству Godot, поэтому будущие
  RigidBody3D (этап 2) сразу подчинятся тем же режимам.
- **Ввод:** touch-кнопки нажимают те же Input Actions, что клавиатура и геймпад, поэтому логика
  игрока одна для всех платформ. Кнопка «Действие» контекстная (по GDD): она появляется, только
  когда рядом есть объект для взаимодействия.
- **Слои физики:** 1 — world, 2 — player, 3 — interactable, 4 — props.
