# RumbStory — «Не открывай» (история 01), нарисовано кодом

Пять вертикальных роликов Reels (1080×1920) по сценарию из `RumbStory — 4 сценария (Nano Banana 2 Edition)`.
Каждый кадр рисуется кодом на движке [ClaudeAnimationBase](https://github.com/JohnHeibel/ClaudeAnimationBase)
(p5.js + p5.brush): плоский цвет, тени в стиле cel shading, чернильный контур, зерно бумаги. Звук тоже синтезирован кодом,
озвучка сгенерирована моделью `openai/gpt-audio` (голос `ash`) через OpenRouter.

## Что где

| путь | что это |
|---|---|
| `vo_lines.json` | текст рассказчика: 5 частей × 10 кадров (колонка «Озвучка» сценария) |
| `tools/tts.py` | генерация озвучки → `audio/vo/pN_KK.wav` (пропускает уже готовые реплики) |
| `tools/timing.py` | хронометраж: длина кадра = max(время по сценарию, длина реплики / 1.12 + паузы) → `studio/src/timing.js` |
| `tools/sound.py` | подложка, звуки по событиям кадров, сведение с голосом → `audio/mix_pN.wav` |
| `tools/render_part.sh N` | рендер кадров части N и сборка `out/RumbStory_01_Ne_otkryvai_partN.mp4` |
| `studio/` | вертикальная копия кита: `src/lib.js` (свет, надписи, переходы), `props.js` (дверь, глазок, замок, часы, телефон, конверт, записка, тетрадь), `places.js` (подъезд, прихожая, спальня, кухня, квартира Семёныча, двор, вид через глазок), `people.js` (Дима, Семёныч, тётя Валя, Оля), `scenes/p1.js … p5.js` |
| `studio/sheet.sh N` | контактный лист части N для проверки (`studio/out/check/pN_sheet.jpg`) |

## Как пересобрать

```bash
python3 tools/tts.py vo_lines.json audio/vo ash   # дозаписать недостающие реплики
python3 tools/timing.py                           # пересчитать хронометраж
python3 tools/sound.py 4 5                         # свести звук
tools/render_part.sh 4 && tools/render_part.sh 5   # отрендерить ролики
```

Для `studio/render.mjs` нужен Chromium; на машине без видеокарты он запускается с `--soft-gl`.
В рендерер добавлен флаг `--disable-accelerated-2d-canvas`: без него Chrome с 10-го кадра замедляется в ~50 раз.

## Отступления от сценария

- Стиль: вместо генерации Nano Banana 2 всё нарисовано кодом, поэтому это упрощённый «плоский» 2D, а не детальное аниме 90-х.
- Хронометраж определяет озвучка: части идут 65–100 с вместо 55–70 с (голос ускорен в 1,12 раза).
- Надписи из колонки «Текст на экране» выводятся в безопасной зоне Reels (верхние 15% и нижние 20% кадра свободны).
