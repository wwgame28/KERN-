# YASMI type beat — «Showbiz 162»

**140 BPM · F minor (Fm – Db – Bbm – C7) · 1:53 · −9.6 LUFS / −1 dBFS**

Бит полностью синтезирован кодом (numpy/scipy), без сэмплов и чужих лупов:
`generate_beat.py` собирает аранжировку, синтезирует каждый инструмент, сводит,
мастерит и выгружает WAV, MP3, MIDI и стемы.

```bash
pip install -r requirements.txt     # + ffmpeg в системе для MP3 и замера LUFS
python generate_beat.py             # output/*.wav, *.mp3, *.mid
python generate_beat.py --stems     # + output/stems/*.wav для сведения в DAW
python generate_beat.py --seed 7    # другая «гуманизация» хэтов и колокольчика
```

## Звук

- **Колокольчик** — FM (4:1 с быстрым спадом индекса + 3.5:1 «звон»), дабл с расстройкой +7 центов, пинг-понг дилей на 3/16.
- **Флейта** — синус с 2-й/3-й гармоникой, вибрато после 150 мс, шум дыхания.
- **Пэд** — суперсо из 7 голосов, LPF 950 Гц, сайдчейн от бочки.
- **808** — моно, ретриггер с питч-панчем, экспоненциальные глайды 30 мс, tanh-сатурация.
- **Ударные** — бочка-свип 187→52 Гц, хлопок из 4 всплесков + снейр, хэты 808-style (6 квадратов + шум), римшот, крэш.
- **Мастер** — HPF 27 Гц, софт-клип, лимитер с look-ahead до −1 dBFS, подгонка громкости по EBU R128.
